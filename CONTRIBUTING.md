# Contributing

This repository is a take-home exercise for interview candidates, not an actively maintained project.

If you are a candidate:

1. Click **Use this template → Create a new repository** and make it **Private**.
2. Add the reviewers as collaborators (Settings → Collaborators).
3. Work on a branch in your new repo.
4. Open a PR from your branch to your repo's `main`.
5. Send the PR URL via the email thread you received the take-home from.

See [README.md](./README.md) for the full prompt.

This is a **template repository** — create your own copy with **Use this template** rather than
forking. Pull requests opened against this upstream repository are not reviewed — the exercise is
the work, not the patch.
